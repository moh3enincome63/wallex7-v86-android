والکس ۷ - بسته اندروید V86 (نسخه آزمایشی PAPER)
=================================================

مبنای کد
--------
فایل main.py مستقیماً از فایل V85 که روی ویندوز آزمایش شده بود برداشته شده است:
Wallex7_V85_PC_TEST_LAYOUT_FIX.py

منطق تصمیم‌گیری ورود و مدیریت ریسک V85 در این بسته عمداً تغییر داده نشده است.
تغییرات V86 فقط برای چرخه عمر اندروید، همگام‌سازی فایل وضعیت، سرویس پس‌زمینه،
و نمایش/برچسب نسخه هستند. دکمه EXIT، بزرگ‌نمایی دو انگشتی و ذخیره/بازیابی
پوزیشن که در فایل V85 وجود داشتند، حفظ شده‌اند.

چه چیزی به V86 اضافه شده؟
-------------------------
1) سرویس اندرویدی PositionGuard با حالت foreground و sticky.
2) هنگام رفتن رابط کاربری به پس‌زمینه، سرویس با همان RiskEngine و همان تابع
   close_demo_position نسخه V85 پوزیشن باز PAPER را بررسی و مدیریت می‌کند.
3) رابط کاربری و سرویس از یک فایل وضعیت مشترک در فضای خصوصی برنامه استفاده
   می‌کنند؛ موجودی، پوزیشن باز، تاریخچه، تنظیمات سرمایه و TP/SL همگام می‌شوند.
4) هنگام بازگشت به برنامه، سرویس ابتدا پایان چرخه مدیریت ریسک جاری را اعلام
   می‌کند؛ سپس وضعیت نهایی به رابط کاربری منتقل می‌شود تا دو موتور هم‌زمان
   یک پوزیشن را نبندند.
5) دکمه EXIT سرویس را متوقف می‌کند. بستن عادی پنجره/رفتن به پس‌زمینه عمداً
   سرویس را متوقف نمی‌کند.

محدودیت‌ها و هشدار مهم
----------------------
- این برنامه فقط DEMO / PAPER است و سفارش واقعی به والکس ارسال نمی‌کند.
- سرویس پس‌زمینه فقط پوزیشن باز را مدیریت می‌کند؛ در پس‌زمینه اسکن ورود جدید
  انجام نمی‌دهد.
- Foreground Service و WakeLock احتمال متوقف‌شدن مدیریت در زمان خاموشی صفحه
  را کاهش می‌دهند، اما تضمین مطلق در برابر Force Stop، خاموش‌شدن گوشی، قطع
  اینترنت، محدودیت‌های سازنده گوشی یا بستن اجباری برنامه توسط Android نیستند.
- مجوز اعلان‌ها و محدودیت مصرف باتری گوشی باید متناسب با نسخه Android بررسی
  شوند. در صورت فعال بودن Battery Optimization شدید، ممکن است سرویس محدود شود.
- این ZIP فقط سورس آماده برای GitHub Actions است؛ APK تا زمان اجرای موفق
  workflow ساخته و آزمایش نشده است. هیچ ادعایی درباره موفقیت ساخت APK نشده است.

ساخت APK
--------
1) محتویات پوشه Wallex7_V86_Android_Project را در ریشه مخزن GitHub قرار دهید.
2) در GitHub بخش Actions را باز کنید.
3) اجرای workflow با نام Build Wallex 7 V86 Android APK را انتخاب کنید.
4) پس از پایان موفق workflow، artifact با نام Wallex7-V86-Android-debug-APK
   را دریافت کنید.
5) APK را روی گوشی نصب و جداگانه این موارد را آزمایش کنید:
   - بازشدن برنامه و بزرگ‌نمایی دو انگشتی
   - بازکردن پوزیشن PAPER و بستن/بازکردن مجدد برنامه
   - روشن ماندن پوزیشن هنگام خاموشی صفحه و بازگشت به برنامه
   - عملکرد دکمه EXIT و توقف سرویس

-------

buildozer.spec                 تنظیمات Buildozer و مجوزهای اندروید
.github/workflows/build-android.yml  ساخت APK با GitHub Actions
